# Folder Studio — downloads

**Make every folder yours.** Give any Windows folder a custom icon — 104 built-in designs (felt, marble, glass,
leather, neon…), an on-device AI Studio, an icon editor for your own images, and one-click undo/restore.

## Download

Get the latest version from **[Releases](https://github.com/dukes-snr/folder-studio-releases/releases/latest)**:

- `FolderStudio_<version>_x64-setup.exe` — recommended. Installs for your user account, no administrator rights needed.
- `FolderStudio_<version>_x64_en-US.msi` — for IT / managed deployment (installs for all users, needs admin).

Windows 10 and 11 (64-bit).

> The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC".
> Choose **More info → Run anyway**.

## Updates

Folder Studio checks this page's latest release for updates and asks before installing. Updates are verified with
Folder Studio's signing key before they run.

This repository only hosts releases; it contains no source code.
